list-style
リストマーカーに関するスタイルを一括で指定する

HTML

    
                        
  1. <ul>
    <li>久しぶり！</li>
    <li>最近元気にしてる？</li>
    <li>たまには会おうね！</li>
    </ul>
    2.

CSS

    
                            
  1. li{
    list-style:decimal inside;
    }
    2.

実例

  • 久しぶり！
  • 最近元気にしてる？
  • たまには会おうね！
特に意味がなかったりする。でも、気持ちとしては本当。

circleで円に指定できる
decimalで数字に指定できる
disc url(ここにURL)で画像に指定できる
outside,insideでリスト項目のコンテンツ・エリアの内側に収めるか外側に出して表示するかの二種類から選択できる
