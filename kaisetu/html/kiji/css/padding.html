padding
要素の内側の余白をまとめて指定する

HTML

    
                        
  1. <p>人と話しているときに
    相槌を２回打つのはあまり話を聞いていないと
    いうことらしい。
    無意識のうちに２回相槌を打って
    いないか心配になる。
    しかし、こんなことを考えているから
    話が頭に入ってこないのだ。
    少し適当なくらいが案外ちょうど
    いいだろう。    </p>
    2.

CSS

    
                            
  1. p{
    padding:30px 5px 100px 0px;
    }
    2.

実例

人と話しているときに相槌を２回打つのはあまり話を聞いていないということらしい。無意識のうちに２回相槌を打っていないか心配になる。しかし、こんなことを考えているから話しているときも内容が入ってこないのだ。
少し適当なくらいが案外ちょうどいいだろう。

要素の内側に余白を作る
値が1つ→4つの辺全てに同じpaddingが適用される
値が2つ→1つ目の値が上下、2つ目の値が左右
値が3つ→1つ目の値が上、2つ目の値が左右
3つ目の値が下
値が4つ→1つ目の値が上、2つ目の値が右
3つ目の値が下、4つ目の値が左
