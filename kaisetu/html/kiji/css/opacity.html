opacity
要素の不透明度を指定する

HTML

    
                        
  1. <p>灰色じゃなくて、
    黒が透けた色    </p>
    2.

CSS

    
                            
  1. p{
    opacity:50%;
    }
    2.

実例

灰色じゃなくて、黒が透けた色

不透明度は要素の裏側に重なったコンテンツの
隠れる度合いで透明度の逆
0.0以上1.0以下のnumber値
または0%以上100%以下のpercentage値を使用する
