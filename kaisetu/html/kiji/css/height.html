height 要素の物理的な高さの寸法を指定する

HTML

    
                        
  1. <h1>下は見ない</h1>
    <!-- この場合は見たほうがいい --!>
    2.

CSS

    
                            
  1. h1{
    height:1000px;
    box-sizing:border-box;
    border:4px solid;
    }
    2.

実例

下は見ない

要素の高さを指定できる
box-sizingでborder-boxを値にすると自分が決めた要素の幅の中でborderやmarginの効果が表れて、content-boxを値にすると要素の幅にプラスしてborderやmarginの効果が表れる
