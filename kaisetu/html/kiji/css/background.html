background
要素の背景に関する指定をまとめて行う

HTML

    
                        
  1. <h1>人は鏡</h1>
    <h3>人は鏡</h3>
    2.

CSS

    
                            
  1. body{
    background:url画像の名前 fixed;
    }
    h1{
    background:green;
    height:100px;
    width:500px;
    }
    h3{
    background:green;
    height:100px;
    width:500px;
    }
    2.

実例

人は鏡

人は鏡

背景の画像、色などを一括で指定する
fixedはスクロールされても背景が動かないようにしている
