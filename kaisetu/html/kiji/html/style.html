<style>
スタイルシートをドキュメントの中で指定する

ソースコード

    
              
  1. <head>
    <style>
    .jiturei{
     height:150px;
     width:500px;
     color:white;
     background-color:好きな色;
     font-size:20px;
     font-family: Georgia, "Times New 
     Roman", Times, serif    ;
    </style>
    </head>
    <body>
    <h1>サンタって、いるらしい。</h1>
    </body>
              
    2.

実例

サンタって、いるらしい。

headタグの中に書くことでスタイルシートを指定できる
一般的には再利用のためにもlinkで外部ファイルを参照するが、一部の例外やテンプレートとは切り離したい場合に使う
