<table>テーブル（表）を作成する

ソースコード

    
                    
  1. <table border="5" width="500">
    <tr>
    <th scope="col">キティが猫ではないと知っている人</th>
    <td>少し</td>
    </tr>
    <tr>
    <th scope="col">キティの正体を知っている人</th>
    <td>0</td>
    </tr>
    2.

実例

キティが猫ではないと知っている人 少し
キティの正体を知っている人 0

※個人的調べ

表を作成できる
trは「Table Row」の略で表の行を作成する
thは「Table Header」の略で表の見出しとなる
tdは「Table Data」の略でセルを作成する
