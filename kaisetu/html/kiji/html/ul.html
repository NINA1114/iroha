<ul>順序のないリストを作成する

ソースコード

                        
    
                        
  1. <ul>
    2. 
                            
  2. <li>hello</li>
    3. 
                            
  3. <li>hi</li>
    4. 
                            
  4. <li>hey</li>
    5. 
                        
  5. </ul>
    6. 
                     

                     
    
                        
  1. <ol>
    2. 
                            
  2. <li>hello</li>
    3. 
                            
  3. <li>hi</li>
    4. 
                            
  4. <li>hey</li>
    5. 
                        
  5. </ol>
    6.

実例

  • hello
  • hi
  • hey
  1. hello
  2. hi
  3. hey

ulはunorderlistの略で順番のないリストを表示する
olはorderlistの略で順番のあるリストを表示する
liはそのままlist
