<div>
ブロックレベル要素としての範囲を指定

ソースコード

    
                    
  1. <div class="name"<p>ただの風邪といっても侮ってはいけません。</p></div>
    2.

CSS

    
                        
  1. .name{
    color:red;
    }
    2.

実例

ただの風邪といっても侮ってはいけません。

<div>は文章の特定の範囲を指定して、一つのまとまりとして扱いたい場合に使用する
<div>を使用すると必ず改行される
idやclassを使ってグループに名前を付ける
