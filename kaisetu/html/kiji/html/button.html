<button>
操作可能なボタンを設置する

ソースコード

    
                    
  1. <button class="styled" type="button">ポチ</button>
    2.

CSS

    
                          
  1. button{
    inline-size:100%;
    padding-block:2rem;
    padding-block:1rem;
    background-color:chocolate;
    box-shadow:inset 2px 2px 3px rgba(255, 255, 255, 0.6),
    inset2px 2px 3px rgba(0, 0, 0, 0.6);
    }
.styled:active{
    box-shadow:inset-2px -2px 3px rgba(255, 255, 255, 0.6),
    inset2px 2px 3px rgba(0, 0, 0, 0.6);
                              
    }

実例

buttonは利用者が任意のタイミングで操作可能なボタンを作成する
JavaScriptと組み合わせることでいろいろな用途に使える
typeという属性でsubmit（データをサーバーに送信する）、reset（データを初期化する）、button（何もしない）というように指定できる
